# d_rocket_builder 2.6.0 — implementation status

The 2.6.0 work adds opt-in generated contracts while preserving the output of
existing annotations.

## Implemented

- `@QueryCache` on `Stream<T>` REST methods, including cache tags, lifetimes
  and generated URL-keyed loaders.
- `@Invalidates` on REST mutations, applied only after a successful response.
- `@Serializable(copyWith: true, equality: true)` helpers with nullable-value
  sentinels and generated equality mixins.
- JSON Schema metadata for generated serializable models.
- `@JsonKey(readValue: ...)` field readers.
- OpenAPI 3.1 export and endpoint metadata import for REST clients.
- Typed `RestPage<T>` decoding in generated REST clients.
- Generated class-level converter bindings through `@JsonConverterBinding`.
- Generated multipart requests for `@Part` parameters.
- OpenAPI output now represents multipart and form-urlencoded bodies.

All generated output is regenerated by build_runner; generated files are not
hand-edited. Runtime integration tests in `d_rocket` compile and exercise the
generated cache and reader contracts.

## Remaining 2.6.0 work

A published-package compatibility matrix remains tracked work. OpenAPI
currently imports/exports endpoint metadata and does not yet generate complete
Dart clients from arbitrary schemas.
